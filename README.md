# Strawberry Hub

Script Blox Fruits — auto farm, combat, matériaux, téléport, shop, anti-détection.
Interface native (aucune dépendance externe), pensée mobile.

## Loader

Colle ceci dans ton exécuteur :

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/redslayer34/strawberry-hub/main/StrawberryHub.lua"))()
```

## Fonctions

- **Auto Farm** — farm level par quête, sélection du type d'arme (Melee / Sword / Gun / Fruit), bring mob
- **Combat** — cible sélectionnée, kill aura, 3 méthodes d'attaque auto-calibrées
- **Matériaux** — farm générique de tous les matériaux
- **Téléport** — îles, voyages inter-mer
- **Shop** — styles de combat, capacités, codes
- **Serveur** — rejoin, server hop
- **Protection** — blocage de la télémétrie de détection/ban/kick
